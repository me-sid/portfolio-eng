Ultimate Library

  • Python
  • Tkinter
  • SQLite

View on GitHub →

Ultimate Library is a desktop-based digital library management application developed using Python and Tkinter, with SQLite handling persistent data storage. It provides a graphical interface for managing book inventory, borrowing records and patron history.

The application has a two-page navigation system, including a Book Guide section.

Book management

  • Add books
  • Check book availability
  • Change book quantities
  • View detailed book information

Borrowing management

  • Issue books
  • Return books
  • Track unreturned books
  • View person borrowing history
  • View book borrowing history

Search and discovery

  • Search books by genre
  • Search books by rating
  • Browse available books

Motivation

Managing books and borrowers by hand is slow and error-prone; this centralises those tasks in one interface.

What I learned

  • Connecting Python applications with SQLite
  • Developing desktop interfaces using Tkinter
  • Implementing database operations
  • Organising application functionality

BankEase

  • Python
  • JSON

View on GitHub →

BankEase is a simple console-based banking management system developed using Python. It uses dictionaries for in-memory account management and JSON for persistent data storage.

It is a menu-driven console application.

Features

  • Account creation
  • Login using account number and PIN
  • Account details
  • Balance enquiry
  • Deposits
  • Withdrawals
  • Money transfers between accounts
  • Transaction history
  • PIN changes
  • Account closure
  • Input validation
  • JSON-based persistent storage

Motivation

A practical way to learn how application logic and stored data fit together.

What I learned

  • File handling
  • JSON data management
  • Functions and modular programming
  • Application logic
